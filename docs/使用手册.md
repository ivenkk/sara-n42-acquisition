# SARA N42 数据采集系统 · 使用手册

面向运维 / 值班人员。开发细节见仓库 `README.md`。

---

## 1. 系统简介与适用场景

本系统运行在能访问仪器内网的 Windows 电脑上，用于：

- **自动采集**：按配置轮询一台或多台 Envinet SARA 能谱仪，约每 5 分钟增量下载 Spectra Folder 中文件名含 `5min` 的 `.n42` 文件到本机。
- **实时查看**：本机网页展示各仪器最新一条能谱曲线、测量时间与剂量率。
- **检索下载**：按测量时间范围检索本地文件，打包为 ZIP 下载。

**适用场景：** 机房 / 值班室长期值守采集；多台 SARA 统一落盘与查询。  
**不适用：** 无法访问仪器局域网的电脑（例如普通云端开发机）。仪器仅提供 HTTP + Digest 认证，必须能直连仪器 IP。

## 2. 环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（部署以 Windows 为准） |
| 网络 | 与仪器同一内网，可 HTTP 访问各仪器 IP（如 `192.168.4.x`） |
| Python | 3.11 及以上 |
| 浏览器 | 本机 Chrome / Edge 等现代浏览器即可 |

## 3. 安装与首次启动

在项目根目录（含 `config.example.yaml`、`sara_n42` 文件夹的目录）打开命令提示符或 PowerShell。

### 3.1 创建虚拟环境并安装依赖

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### 3.2 准备配置文件

若还没有 `config.yaml`：

```bat
copy config.example.yaml config.yaml
```

用记事本或其它编辑器打开 `config.yaml`，至少确认：

- 仪器 `host`（IP）正确
- `username` / `password` 已换成该仪器的 **HTTP Digest** 账号（示例里是占位符，见下一节）
- 展示页端口默认 `8080`，一般无需改动

### 3.3 启动服务

```bat
.venv\Scripts\activate
python -m sara_n42
```

或指定配置路径：

```bat
python -m sara_n42 -c config.yaml
```

启动后程序会：

1. 立刻做一轮远程检查与增量下载  
2. 之后约每 **300 秒**再检查一次  
3. 在本机提供网页：

| 页面 | 地址 |
| --- | --- |
| 实时能谱 | http://127.0.0.1:8080/ |
| 检索下载 | http://127.0.0.1:8080/search |

控制台会打印 INFO / ERROR 日志；下载明细另见 `data/download.log`。

**停止服务：** 在运行窗口按 `Ctrl+C`。

## 4. 配置仪器

编辑项目根目录下的 `config.yaml`（不要提交真实密码到公开仓库）。

### 4.1 示例（占位符，非真实口令）

```yaml
storage_root: ./data
poll_interval_seconds: 300
filename_contains: "5min"
file_extension: ".n42"
request_timeout_seconds: 20

ui:
  host: "127.0.0.1"
  port: 8080

instruments:
  - name: "SARA-1"
    host: "192.168.4.136"
    port: 80
    username: "YOUR_USERNAME"
    password: "YOUR_PASSWORD"
  # - name: "SARA-2"
  #   host: "192.168.4.137"
  #   port: 80
  #   username: "YOUR_USERNAME"
  #   password: "YOUR_PASSWORD"
```

### 4.2 增删改仪器

| 操作 | 做法 |
| --- | --- |
| 增加仪器 | 在 `instruments` 下按同样格式追加一条（`name` / `host` / `port` / `username` / `password`） |
| 删除仪器 | 删除或注释掉对应条目 |
| 改账号 / IP | 直接改该条目字段后保存 |

### 4.3 热加载说明

- 保存 `config.yaml` 后，**运行中的程序会自动重载**仪器列表与轮询相关设置，一般**不必重启进程**。
- 浏览器请**刷新页面**（或等自动刷新），实时能谱面板数量才会与新配置一致。
- 若 YAML 写错（格式无效），程序会保留上一份有效配置，并在控制台打 ERROR 日志。
- 修改 `ui.host` / `ui.port`（绑定地址与端口）后，**必须重启服务**才生效。

## 5. 日常使用：实时能谱页 `/`

打开：http://127.0.0.1:8080/

页面为每台已配置仪器显示一块面板：

- **在线且有本地最新谱**：显示能谱曲线、文件名、测量时间、剂量率（来自 N42 中 CountDoseData / DoseRate；没有则显示「未知」）。
- **不在线**：面板标题与提示为「**不在线**」（仪器探测失败、不可达，或尚无可用本地最新文件时）。底部状态栏会显示类似「已更新：x/y 台在线」。
- 多台仪器时自动网格排布。
- 可用「刷新」按钮；默认按轮询周期自动刷新（可取消勾选）。

顶栏可切换到「检索下载」。

---

## 6. 日常使用：检索下载页 `/search`

打开：http://127.0.0.1:8080/search

1. **仪器**（可选）：选某一台，或「全部仪器」。  
2. **测量时间起 / 止**：日期 + **24 小时制**时间 `HH:MM`（例如 `09:30`、`18:05`）。页面默认填入近 24 小时。  
3. 点 **检索**：只显示匹配**数量**，不列出文件名。  
4. 有匹配时点 **下载 ZIP**：打包本地匹配的 `.n42`（包内按仪器 IP 分目录）。

时间格式错误时页面会提示，请改成 24 小时制后再检索。

## 7. 本地存储目录结构

默认根目录为 `./data`（相对程序启动目录，可在配置里改 `storage_root`）：

```text
data/
  192.168.4.136/
    2026-11/
      *.n42
    2026-12/
      *.n42
  192.168.4.137/
    2026-11/
      *.n42
  download.log
```

要点：

- 第一层目录名为仪器 **IP**，其下按测量月份 **`YYYY-MM`** 分子目录。  
- 只保存扩展名 `.n42` 且文件名含 `5min`（大小写不敏感）的文件。  
- 保留仪器上的原始文件名；同名文件已存在则跳过，不覆盖。  
- `download.log`：下载成功 / 失败记录，便于排查。

## 8. 常见问题

### 改了 config.yaml，页面仪器数量没变？

先确认文件已保存。热加载一般无需重启；请**刷新浏览器**。若改的是 `ui.host` / `ui.port`，需要**重启服务**。YAML 写错时配置不会生效，请看控制台 ERROR。

### 某台仪器显示「不在线」？

依次检查：电脑能否 ping / 浏览器访问该仪器 IP；`config.yaml` 中 IP、端口、Digest 账号是否正确；仪器是否开机、网络是否正常。单台失败不影响其它仪器继续轮询。控制台与 `data/download.log` 可看具体错误。

### 检索结果为 0、没有文件？

确认服务已运行且调度在下载（不要长期用 `--no-scheduler` 值班）；时间范围是否覆盖测量时间；该 IP 下 `data/{IP}/{YYYY-MM}/` 是否已有 `.n42`；文件名是否含 `5min`。刚启动时可能还没完成首轮下载，可稍等数分钟后再查。

### 如何重启服务？

在运行窗口 `Ctrl+C` 停止，再执行：

```bat
.venv\Scripts\activate
python -m sara_n42
```

### 页面打不开？

确认命令窗口仍在运行；地址是否为配置中的 host/port（默认 `127.0.0.1:8080`）；本机防火墙是否拦截；端口是否被占用。

---

## 9. 值班快速检查清单

1. 服务窗口在跑，无持续 ERROR 刷屏。  
2. 打开 `/`，各台状态合理（在线有谱，或预期离线显示「不在线」）。  
3. `data/{IP}/当前月份/` 下有近期 `.n42`。  
4. 需要导出时到 `/search` 用 24 小时制时间检索并下载 ZIP。  
5. 增删仪器：改 `config.yaml` → 保存 → 刷新浏览器；改端口则重启服务。
